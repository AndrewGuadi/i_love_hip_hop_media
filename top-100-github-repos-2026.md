## How to Use This List

**Start with your bottleneck:**
- Building LLM apps? Start with **LangChain**, **Dify**, or **Mastra**.
- Need to run models locally? **Ollama** + **Open WebUI** is the fastest path.
- Want agents that code? **OpenCode** or **Pi** for terminal, **Cline** for VS Code.
- Building multi-agent teams? **CrewAI** for roles, **AG2** for conversations, **MetaGPT** for software teams.
- Need browser automation? **browser-use** for AI agents, **Playwright** for deterministic automation.
- Shipping to production? **vLLM** for serving, **LiteLLM** for routing, **Langfuse** for observability.
- Making games? **Godot** for general, **Bevy** for Rust, **gamedev-skills** for AI-assisted dev.
- Need compliance? **Probo** for GRC, **Vault** for secrets, **Trivy** for scanning.
